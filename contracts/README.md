# Mission pack v1

This candidate fixes the wire format for implementation and awaits review by Yumeth, Senula and Isath. It recognizes exactly two capabilities: `routing_simulation` for synthetic packs and `elevation_preview` for source-backed packs. Tactical routing is outside v1. A consumer must explicitly enable simulation. Neither capability establishes Marswalk safety.

A pack is a dedicated immutable directory with `site.json` and the manifest-listed artifacts. Every artifact has one flat relative filename, exact byte length and SHA-256. The caller supplies an independently trusted site hash when accepting a release. Validate strict integer versions before reading payloads. Validate JSON Schema for structure and validate cross-file relationships, CRS, geometry, masks and evidence separately. Payload checks precede parsing. Refuse invalid or unsupported inputs with stable error codes. The contract assumes immutable local pack directories.

Analytical terrain uses C-contiguous little-endian Float32 metres in `z_m` and Boolean `valid_mask` and `screen_excluded_mask`, all with shape `[rows,cols]`. A true validity bit means analytical support. A true screening bit excludes a valid cell. Unsupported cells carry NaN and valid cells carry finite elevations, including zero. Request closures do not modify either baseline mask. NPZ contains just these three arrays with no pickle objects.

Affine coefficients are `[a,b,c0,d,e,f0]`. The centre of raster cell `[r,c]` has metre coordinates `[c0+a*(c+.5), f0+e*(r+.5)]`. V1 requires north-up, (a>0), (e<0), no skew and outer edge bounds ordered west, south, east, north. The WKT supplies projected easting and northing on a Mars sphere. The source and local CRS, metre units and vertical reference are explicit. Evidence queries use canonical planetocentric latitude and east-positive longitude in degrees.

Preview uses a C-order little-endian Float32 grid with its own descriptor and recorded source reference. The loader recognizes the archive-verified Jezero window by its raster digest and requires its verified shape, affine and bounds. A preview pack has no analytical mask, scenario or station payload. Keep native sampling separate from effective scale, evidence support separate from the raster extent, and source validity separate from screening. Evidence packages use the [marsdoc evidence schema](../documentation/schemas/evidence-package.v1.schema.json). They link to source IDs and versions through the pack's source manifest. G10 starts unevaluated and a later acceptance receipt lives outside the pack.

Run `uv run --project documentation --locked python -m pytest contracts/tests -q` from the repository root. See `fixtures/synthetic-v1` for a reproducible 3×5 software fixture. `tests/test_pack_contract.py` provides independent coordinate, mask, eligibility and refusal checks. Its scenario specifies a four-neighbour test model only. The expected crew-to-home time is 40 s (reverse 48 s), 60 s after closing the middle cell, and unavailable after closing both corridors. The modeled science action changes from 75 s to 95 s against 85 s available after reserve.

For the source-backed handoff, set `RW_JEZERO_WINDOW` to the pinned Float32 file and run `uv run --project documentation --locked python -m pytest contracts/tests/test_producer_consumer.py -q`. The test builds a pack and invokes the real runtime loader, verifies the bytes and geometry, and exercises the refusal and corruption paths. See the [asset reconstruction instructions](../evidence/jezero/README.md). The synthetic fixture generator exercises the separate simulation path. A general analytical terrain producer still needs to emit and pass this interface.
