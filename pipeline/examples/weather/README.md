# Weather forecast example (SYNTHETIC)

- `synthetic-station.csv`: 1050 synthetic sols in the canonical station format (`sol, ltst_h, ls_deg, pressure_pa, air_temp_k, wind_ms, dust_tau`). Generated by `python -m return_window_pipeline.forecast synth --out synthetic-station.csv`. Amplitudes are illustrative and not fitted to any mission.
- `synthetic-station.json`: station metadata in the format `train` expects.
- `synthetic-forecast-report.md`: the evaluation tables `train` writes. It shows the report format only. **The numbers are not Mars skill.**

Real datasets and their verification status are listed in [docs/weather-forecast-datasets.md](../../../docs/weather-forecast-datasets.md).
